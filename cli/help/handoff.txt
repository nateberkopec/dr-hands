Usage: dr-hands handoff RUN_ID FINDING
Write a coding-agent prompt for one finding from fixed dr-hands text. Use only
schema-valid finding fields. Check canary names against RUN_ID's target and each
location against the operator's checkout at the target's configured commit.
Label the prompt unverified unless a verify run captured every claimed canary.
Use agent-channel fields only: verified status, captured canaries with their
configured descriptions and classes, capturing identities, CWE, CVSS base
vector, HTTP methods, and checked locations. Never include a transcript,
verdict.md, the report, or other guest-written content; those are for the
operator. Ask for a regression test with benign inputs. Create no resources.
